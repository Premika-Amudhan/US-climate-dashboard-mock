# US-climate-dashboard-mock
This interactive dashboard visualizes simulated climate risk data - including **heat index** and **flood risk** - across U.S. states. It is built using **Python**, **Streamlit**, and **Plotly**, and allows users to explore patterns by region and indicator through a dynamic choropleth map
## Features

- State-level choropleth visualization of climate risk indicators
- Sidebar selection of indicator (Heat Index or Flood Risk)
- Interactive map with hover functionality displaying detailed values
- Responsive web interface built with open-source tools

---

## Technologies Used

- Python 3.9+
- Streamlit
- Plotly Express
- NumPy
- Pandas
